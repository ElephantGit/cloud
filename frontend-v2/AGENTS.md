# frontend-v2

The production Cloud v2 web frontend (see the v2 section of the root `AGENTS.md`): Vite, React 19,
TypeScript, Tailwind CSS 4, shadcn (base-nova, Base UI), TanStack Query, zustand, React Router.
The UI is Chinese. It does not follow the specs process, and `frontend/AGENTS.md` does not apply.

- **One feature per directory.** Each page in the left icon rail lives in `src/features/<name>/`:
  `index.ts` exports its `Feature` (path, title, icon, lazy page) and `page.tsx` its page. Register it
  with one line in `src/app/features.ts`. Keep a feature's components, hooks, stores and tests inside
  its directory so features can be built in parallel without touching each other; code two features
  need moves to `src/components/` or `src/lib/`.
- **`src/app/`** is the shell: providers, routes, layout and the icon rail. Change it only for behavior every
  page shares.
- **`src/components/ui/`** is generated by `npx shadcn@latest add <component>`; do not hand-edit it, and
  lint skips it.
- **Server state** goes through TanStack Query, **client state** through zustand stores owned by the
  feature. Talk to the backend only through the HTTP contract (`/api`, proxied to v2-server in
  development); the client generated from `api/openapi.json` lands with the skeleton.
- Every page keeps a test in its feature directory once it has behavior. `npm run check` (types, lint,
  tests, build) is the gate the v2 workflow runs; run it before pushing.
