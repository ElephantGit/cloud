# Dashboard

`/dashboard` 上方展示当前工作区的真实任务概览，下方保留会话分析。顶部提供分区锚点；旧 `/dashboard/sessions` 入口兼容同页分析区，详情位于 `/dashboard/sessions/:id`。

## 团队概览

通过共享的生成任务客户端 `src/lib/tasks-api/generated.ts` 读取当前成员有权访问的完整任务列表和每项任务的运行记录。请求按用户、工作区隔离缓存，支持手动刷新及每 30 秒重新读取。列表不完整或任一读取失败时显示错误，不用演示数字或部分结果代替完整统计。任务时间轴最多四个并发请求。

- 进行中、待验收、已完成：当前任务状态数量；待处理显示在进行中卡片的说明里。
- 本周任务 Agent 运行：按浏览器本地时间、本周一零点起创建的任务运行数；执行成功数量使用这些运行各自最新一轮的结果。普通 Chat 和独立工作流会话不在这个指标内。
- 团队进度：按当前负责人分组，包含成员、Agent、小队及未指派。只显示有未取消任务的负责人；小队任务不复制给每个队员。完成率为已完成 /（待处理 + 进行中 + 待验收 + 已完成），不把待验收算作完成。
- Agent 产出：最新任务运行成功，且任务当前处于待验收或已完成的项目，最多显示六项。说明来自任务描述，链接进入真实任务，不把任务描述当成 Agent 生成的报告。
- 近 7 天任务更新趋势：按任务最后更新日期统计，包含编辑与状态变化。现有任务契约没有可靠的完成事件时间，因此不把这个图标为完成趋势。

概览不受 `VITE_DEMO_MOCK` 控制，没有任务时显示空状态。数据来源是当前服务端数据库，其中既有预置样例仍按其真实名称显示。旧协作功能的任务客户端路径保留为共享客户端的转导出，避免两套生成客户端各自演进。

## 会话分析

始终读取真实后端。支持来源、项目、Agent、最后一轮状态与时间范围筛选；时间按本地下界含/上界不含转为 UTC。当前支持自己的普通对话和当前成员可读的手动协作任务 Agent 会话，详情保留概览、模型请求、时间轴、工具统计及完整事件，并可返回来源。未知时间、缺失用量和未采集的请求统计保持原义；授权失败隐藏旧详情。

Agent 筛选使用完整标识（例如 `official/ora-space.opencode`），不是显示名称或执行器短名；预置样例与现场会话使用同一标识，因此可以按同一 Agent 查询。普通 Chat 通过 `/chat?conversation=<id>` 返回原对话；会话仅向其创建者开放，失效来源提示已删除或无权访问。

历史是 PostgreSQL 定型记录快照，不是 Revision 完整归档。历史与模型统计独立读取；授权失败隐藏旧详情，统计刷新失败隐藏旧数值。模型明细保留 fixture/上游来源，汇总覆盖全部已记录请求，趋势仅覆盖当前页；未观测的请求不估算用量。

`task v2:demo:lead` 与合成 `task v2:demo` 沿用 B 段装配。陈默的「预置分析样例（非现场执行）」仍可在会话分析查看，其历史不是现场执行、没有伪造请求统计；任务时间轴的 `demoSeed` 由服务端按持久化的 seed 专用身份标记。团队概览运行数和 Agent 产出排除这类非执行样例；任务状态及更新趋势仍反映任务表中现有记录。实际执行即使使用 fixture 模型，也不等同于预置样例。当前数据无法提供该标记时，概览显示读取失败，不将未知来源默认当成真实执行。
