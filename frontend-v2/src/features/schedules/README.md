# 定时任务

原列表、概览、筛选、启用开关及右侧抽屉统一承载所有定时配置，不另设预览页或体验入口。在「新建任务」的执行方式中选择「已有任务」，可以搜索编号/名称、按项目筛选、预览描述、填写补充说明并设置时间；选中后在摘要卡片中更换或清除任务。直接对话仍是创建时的默认方式，工作流暂未开放；编辑时保留执行方式，已有任务可更换来源。

已有任务使用明确标注的演示目录，配置与运行记录仅保存在按用户和租户隔离的内存中，刷新后清除；原有直接对话配置继续真实持久化。新类型的记录在原表格标注「演示」，复用原筛选和开关，详情提供配置与独立运行历史。每次模拟读取来源最新描述和项目，历史保留当次快照；已完成来源继续可用，失效来源禁止保存和模拟。不会读取历史对话、修改任务状态、创建普通对话或调用配置/执行写入接口。模拟只能手动触发，不启动自动调度，不代表真实执行契约。`E2E_WEB_PORT` 可覆盖端到端测试的前端端口，默认仍为 5174。

列表与右侧抽屉支持保存、编辑、暂停和恢复无项目文本任务配置，配置通过 v2-server 持久化，刷新后保留。工作流、项目、模型选择、真实执行、删除和真实运行历史尚未接入；已保存的文本配置不会生成模拟运行结果。

时间规则支持每天、工作日、每周及固定小时间隔；日历规则按任务时区预览，间隔以创建时间为起点。预览不代表调度已启用。

临时 v2 配置接口由 `v2-server/schedules.openapi.json` 描述，使用 `npm run api:generate:schedules` 生成本功能客户端；正式 Cloud 的接口缺口见 v2-server README。会话和租户继续通过正式生成客户端读取。

`npm run check` 运行类型检查、lint、单元测试和构建。`npm run e2e` 使用真实 v2-server 与 PostgreSQL 验证页面；可通过 `E2E_DATABASE_URL` 和 `PW_CHROMIUM_PATH` 指定数据库与浏览器。
