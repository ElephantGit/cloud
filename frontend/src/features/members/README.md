# members：租户成员管理

## 职责

展示当前协作空间的租户成员，并让管理员修改有效成员角色或停用成员。已停用者重新加入须经过新一轮人员核验、邀请或申请批准。华为部署从天舟搜索在职人员并添加；公网部署生成邀请与申请链接、撤销链接和审批申请。

不负责登录、空间切换或保存邀请令牌原文。

## 文件

| 文件 | 说明 |
| --- | --- |
| `api.ts` | 租户成员、人员目录、链接与申请的生成客户端 hooks；本地随机令牌 |
| `members-page.tsx` | 成员表及按登录提供方选择的管理入口 |
| `members-page.test.tsx` | 成员权限、停用、链接生成和目录添加测试 |
| `member-roster.tsx` | 紧凑成员表、管理员操作与只读加入历史 |
| `join-links.tsx`、`join-requests.tsx` | 两类链接、生命周期、来源统计和申请审批 |
| `create-link-dialog.tsx`、`browser.ts` | 弹窗拥有分享原文；复制失败与关闭确认；本地时间和到期刷新 |
| `directory-add.tsx`、`translations.ts` | 企业目录入口与成员/加入的中英文词汇 |

## 依赖与不变量

依赖 `features/spaces/current-space`、`features/auth/providers`、生成客户端和 UI 组件；设置路由消费本模块。

- 角色与状态仅来自租户成员接口；移除写为 `disabled` 并保留成员行。
- 租户成员写接口不能直接新建或恢复成员，避免绕过目录在职核验与私有加入流程。
- 管理功能只向 `admin` 显示；内网添加通过 Ora 服务端重查人员，不向浏览器提供天舟密钥。
- 浏览器生成 256 位令牌，只在创建成功时显示分享链接；之后列表只含元数据。
- 默认展示成员，管理员才挂载待审批和加入链接；普通成员不查询管理历史。来源未知时不从兑换者反推。
- 备注用于辨认链接，不绑定接收人；生成弹窗关闭或切换工作区即丢弃原文。再次复制不增加使用次数。
