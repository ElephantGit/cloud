# squads：小队管理入口

[English](README.en.md)

小队管理尚未开放。列表和旧详情链接显示明确的不可用说明，提供当前工作区“设置 → 成员”的入口，帮助用户查找已接受邀请的真实成员。页面不读取演示小队、成员或项目，不虚构人数、在线状态或可执行能力，也不将工作区成员资格解释为已加入某个小队。

| 文件 | 职责 |
| --- | --- |
| `squads-page.tsx` | 小队不可用说明与真实成员导航 |
| `squad-detail-page.tsx` | 旧详情 URL 复用说明，不解析演示身份 |
| `*.test.tsx` | 工作区导航、旧详情及演示记录排除验证 |

依赖 unavailable 与 lib/paths，由路由组合根消费。真实邀请及成员授权由 members 模块和后端拥有，本模块不修改成员关系、不启动任务。导航始终保留传入的工作区 slug，不回退到演示工作区。
