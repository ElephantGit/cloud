# 服务端时间计算

`Next(rule, created, after, count)` 计算严格晚于 after 的 1–3 个 UTC 时刻，不读取当前机器时钟，也不触发执行。固定小时间隔以配置创建时间为锚点；每天、工作日和每周按 IANA 时区的墙上时间计算。日历计算不早于创建时间。

夏令时不存在的本地时刻跳过；同一天重复出现的本地时刻仅取第一次，避免重复触发。日历搜索最多32天，支持的规则在该范围内应能得到三次时间；输入错误返回错误，不默默改成 UTC。时间预览由服务调用方提供时钟，测试覆盖年末、周末、每周、间隔及 DST 跳时/回拨。

当前只有 Go 计算接口，没有 HTTP 预览路由或周期扫描器。前端仍使用既有预览函数，正式接入前需以此服务端规则统一展示和触发判断；本模块不决定停机处理、执行接收或执行时长。消费方采用忙即跳过，不实现等待窗口；跳过和手动重跑不应移动这里使用的原计划锚点。
